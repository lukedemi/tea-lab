# Mystic Mint (Rishi copy)

Rishi's ingredients, heaviest first: peppermint, cardamom, licorice root, essential basil and clove leaf oils.
A whole clove and a little dried basil stand in for the oils.

## Full version, v1 (5.00 g, for a 12-16 oz mug)

| Ingredient | Grams | Notes |
|---|---|---|
| Peppermint | 3.50 | |
| Green cardamom | 0.75 | About 4 pods, cracked open |
| Licorice root | 0.60 | |
| Dried basil | 0.10 | Stands in for basil oil |
| Clove | 0.05 | About half a whole clove |
| **Total** | **5.00** | |

## Pantry version (no cardamom), v1: keeper, tasted balanced

For a normal 10-12 oz coffee mug.

| Ingredient | Grams | % |
|---|---|---|
| Peppermint | 3.00 | 75 |
| Licorice root | 0.70 | 17.5 |
| Cinnamon (broken stick) | 0.30 | 7.5 |
| **Total** | **4.00** | |

Brew (house method, see [BREWING.md](../BREWING.md)): 208°F, 11 oz mug, Finum basket with lid on. Steep 6-8 min.

## Brew log
- 2026-11-05, pantry version, as brewed: peppermint 3.00 g, licorice root 0.70 g, cinnamon 0.30 g (4.00 g total), normal coffee mug. Percentages: 75% mint, 17.5% licorice, 7.5% cinnamon. More licorice- and cinnamon-forward than the 5 g plan.
  - Taste: pretty decently balanced. Keeper as the house pantry version.
