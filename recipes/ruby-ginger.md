# Ruby Ginger, v1

Original blend for a light, bright pre-lunch cup. Tart and gingery, lightly sweet. Made from the pantry with no mint.

| Ingredient | Grams | % |
|---|---|---|
| Rosehips | 1.80 | 45 |
| Ginger root, chopped small | 1.00 | 25 |
| Hibiscus flowers | 0.80 | 20 |
| Cinnamon (broken stick) | 0.25 | 6.25 |
| Licorice root | 0.15 | 3.75 |
| **Total** | **4.00** | |

Brew (house method, see [BREWING.md](../BREWING.md)): 208°F, 10-12 oz mug, Finum basket with lid on. Steep 6-8 min.

Cost: about $0.24 per cup (store prices; cinnamon estimated from Mountain Rose Ceylon sticks).
